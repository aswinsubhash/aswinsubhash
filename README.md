## About me

I’m **Aswin Subhash**, a mobile application developer based in **Dubai, UAE**, with 3+ years of experience building and shipping production Flutter applications.

I work across the product lifecycle—from system design and UI implementation to API integration, testing, release automation, and production monitoring. I enjoy turning complex workflows into clear, maintainable experiences that perform well in the real world.

- **Focus:** Flutter, Dart, cross-platform mobile development
- **Platforms:** Android and iOS
- **Strengths:** Clean Architecture, state management, performance, localization, and CI/CD
- **Experience:** Production apps shipped across the UAE, Japan, Saudi Arabia, and beyond
- **Currently:** Building mobile products and AI-augmented engineering workflows

`Flutter` `Clean Architecture` `BLoC` `Dio` `GetIt` `go_router` `RTL/LTR`
