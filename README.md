## About

I’m Aswin, a Flutter developer based in Dubai. I build and maintain mobile applications for Android and iOS using Dart.

I usually work across the whole app: interface development, state management, API integration, local storage, payments, maps, analytics, crash reporting, and release workflows.

I prefer code with clear ownership and predictable behaviour. Features should be straightforward to change, failures should be handled explicitly, and the interface should work well across screen sizes and languages.

## How I build

<table>
  <tr>
    <td width="50%" valign="top">
      <h3>Application structure</h3>
      <p>Feature-first modules, clear layer boundaries, dependency injection at the composition root, and minimal coupling between features.</p>
    </td>
    <td width="50%" valign="top">
      <h3>State and data</h3>
      <p>Explicit states, predictable transitions, typed failures, repository-owned data access, and offline behaviour where the product needs it.</p>
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h3>Interface</h3>
      <p>Responsive layouts, localization and RTL support, accessible interactions, and motion used only when it improves context.</p>
    </td>
    <td width="50%" valign="top">
      <h3>Release and monitoring</h3>
      <p>Automated builds, crash reporting, analytics, staged releases, and over-the-air updates when they are the right fit.</p>
    </td>
  </tr>
</table>
